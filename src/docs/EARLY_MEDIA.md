# U30 Air 接通前运营商语音（短时实机验收通过）

2026-11-05：在 R21 源码上增加普通 VoWLAN 与云端早期下行，候选二进制版本 `0.1.0-r21-early.1`。已安装到 U30 Air，用户确认 VoWLAN 与云端的运营商语音可听、未提前计时、接通后双向正常；现已纳入重新发布的 R21。该结果不代表长时稳定性或全部异常场景通过。AirSIM iOS/Android、Relay、系统、内核和 DSP 固件均未修改。

R20 / R21 已发布版本的普通服务没有启用早期媒体；历史可听记录来自限时单通话试验。新候选将普通 VoWLAN 的接收通道启用，并补上云端尚未接通时的下行转发。明确选择旧试验入口时，仍执行原有有效期与单通话限制。

## 实现与边界

- VoWLAN 沿用客户端已有签名授权、30 秒租约续期及 `AIRSIMEM1` 接收协议。需客户端支持该接口。
- 云端复用已有已认证 WebSocket 与 PCM 分帧，保留 8 kHz / 单声道 / S16LE / 20 ms。只发送 `early_media` 状态和实际采集帧，不伪造 `active`、接听或接通计时。
- 从云端拨号成功的持久回执记录本地 MU300 UUID，分别保留 Relay call ID / UUID / generation。旧会话不能通过“当前还有一通呼出”接到下一通电话。
- 内部 `127.0.0.1:7581/internal/cloud-early-media` 调用 Agent `127.0.0.1:8575/api/calls/cloud-early-media`，两者均不在 LAN RPC 白名单中。要求当前云端描述符、持久 relay 拨号归属及本地通话一致。
- 必须存在新鲜、唯一未接通呼出及本次 `+EARLYMEDIA: 1`；无信令、旧信令、轮询失败、通话替换不能打开或保留早期采集。
- 与正常双向音频共用独占资源，接通前只开 capture，不开 aplay。手机可能已经发送的上行在设备端丢弃，不缓冲到接通之后。
- 接通、挂断、身份变化、断开或信令失效取消早期采集；等待采集进程和 DSP 清理后释放资源，正常双向连接仅在真实 active/held 后建立。云端早期阶段最长三分钟，有首帧、停流、写出超时。
- 不生成“暂时无法接通”等录音，不延长已经确认结束的基带通话。运营商不提供早期媒体时，无运营商语音可转发。

已验证环境限 U30 Air / 5.4.254-gb50db5b6224c 的既有音频链路。F50、7.2.8 及其他硬件未适配。信令与媒体证据分别记录如下。

## 自动化验证

覆盖普通模式无试验许可即可协商、显式试验仍限时、远程地址和非法请求拒绝、内部接口不经 LAN 转发、云端 Relay 与本地通话绑定、旧 generation/UUID/槽复用拒绝、过期轮询与信令丢失、分片 PCM 重组、接通前无上行和无 active 状态、接通/结束/替换/断网退出、并发采集互斥、释放后可再次使用。沿用既有 VoWLAN 签名、续期、重放和音频资源释放测试。

## 用户实机验收（2026-11-05）

候选 `0.1.0-r21-early.1`，由用户手动拨打自己的测试手机，分别使用 VoWLAN 与云端完成拒接和接听测试；助手未拨号、未录音。

| 验收项 | VoWLAN | 云端 | 依据 |
| --- | --- | --- | --- |
| 接通前运营商提示音可听 | PASS | PASS | 用户明确确认 |
| 接通前不提前计时 | PASS | PASS | 用户明确确认 |
| 接通后双向声音正常 | PASS | PASS | 用户明确确认 |

收到两项反馈后，只读检查确认当前通话已空闲、音频采集已退出、Agent 可达、音频依赖可用。这个空闲快照不替代双向听感证据，也不能证明每种结束路径都已覆盖。安装保留了设备身份和配对、系统与内核，未重启设备。

长时稳定性、断网重连、重复快速拨打及所有运营商拒接场景仍未完整验收；F50 等其他硬件不在本次结论内。上述修复纳入 2026-11-05 重新发布的 R21；旧版 R21 的默认关闭行为仅作为历史记录。

## 后续回归步骤

VoWLAN 和云端分别测试：

1. 手动拨打自己的测试电话，由对端拒接或不接；有运营商公告时确认可听，未接通不计时，基带结束后页面收尾。
2. 再手动拨打，由对端接听；确认公告/回铃转双向无持续静音，两边轮流说话，随后由对端挂断。
3. 紧接着重复一通，确认资源已释放，没有自行重拨。

测试只观察脱敏状态和计数，不录音。安装候选需空闲检查、设备内备份和可回退脚本，短暂重启插件服务，不重启设备。正式重新发布须重新构建、签名、完整校验并公开说明同名资产更新，不能直接上传测试二进制。

## R22 云端协议协作

R22 纳入云端 `early_media_version: 1` 和 `early_media_ready_v1` 协商；未协商的旧客户端仍可接通后通话，但不进入云端早期采集。用户已反馈当前通话体验验收通过；此前设备运行 R21 候选，新 v1 协商与 R22 完整包没有单独实机安装证据。客户端 171 同时兼容 R21 旧状态名。具体兼容差异与验收边界见 [协议交接](handoff/2026-11-05-cloud-early-media-v1.md)。
