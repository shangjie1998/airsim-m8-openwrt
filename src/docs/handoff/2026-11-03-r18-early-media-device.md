## 已实现

### 信令与身份

Agent 内部 `GET /api/calls/early-media?call_id=...` 只提供信令证据，不签发媒体能力。它要求可信网关注入的配对身份、持久拨号回执中的归属、同一个未接通呼出 UUID、最近 2.5 秒内的成功单路 CLCC，以及新鲜读到的 `+EARLYMEDIA: 1`。接口本身不发送 AT、不启动音频。

原 `operations.json` 增加可选 `owner_digest`，保存内部 owner 字符串的 SHA-256。旧记录仍可持久去重，但没有归属摘要时不能授权早期音频。不把号码、基带槽号或历史记录当作配对归属。

EARLYMEDIA 只关联已有的唯一呼出 UUID；启动积压、日志轮换、无效事件、信号取消、失败/过期查询、空列表、active、结束或换通话均不能沿用旧权限。不改变通话状态，不将指示解释成拒接原因。

### 网关契约

现有 VoWLAN HMAC 鉴权后处理 `/api/calls/early-media`：

| 状态 | 行为 |
| --- | --- |
| 200 | 签发 EarlyMediaGrant v1，严格绑定 Agent / 原通话 / session / GET nonce |
| 202 | 授权或本通话早期下行信令未就绪，可按客户端限次策略等待 |
| 401 / 403 | 认证、归属不成立，不开启音频 |
| 410 | 原通话、信令、试听范围或权限已不能继续；不代表伪造通话终态 |
| 501 | 默认生产模式：完整早期媒体生命周期尚未验收，不提供能力 |

字段和签名逐项沿用客户端交接的 `AIRSIM-EARLY-MEDIA1`。每张媒体授权最多 30 秒；同一 owner / call 的续期保持 session_id，延长运行中的租约。保留尚未到期的已签发 expiry 值供新握手验证，最多 30 个整秒值。没有签发过的 expiry、其他配对方、其他通话、错误 session、过期或重放均拒绝。

独立 PCM 握手 `AIRSIMEM1 timestamp nonce signature base64(binding)\n`：binding 用标准 Base64，HMAC 为原有 base64url，签名 method=`PCM`、path=`/v1/pcm/early-media`。不降级到旧双向握手。

### 下行与生命周期

- `internal/audio/early_media.go` 只启动 arecord 下行采集，不创建 aplay / AP 上行队列，不把客户端字节送入 DSP。
- 拿到第一帧真实采集源数据并再次核对授权后才发 AIRSIMREADY。不生成静音填充、不合成提示音；自然采集到的静音不等于已听到运营商公告。
- 任意客户端上行字节使会话关闭。断开、租约到期、查询不可靠、active/终态或撤销试听权限均停止早期通道。
- 租约每 100ms 检查，信令约每 300ms 读取 Agent 缓存，单次读取超时 1 秒。还受 Agent 本身轮询延迟约束；不是基带事件硬实时回调。
- 启动首帧最多等 8 秒；后续源流超过 3 秒无帧即关闭，不用假音频保活。
- 与原双向 Bridge 共用互斥；先关闭/等待采集进程，再停止 DSP 场景，再释放资源。正常 PCM 切换可等待早期会话完成清理，避免并发占用。
- 守护进程退出会等待 LAN PCM 会话和音频清理；不会只等旧 loopback 会话就退出。

## 默认关闭与可执行的临时试听入口

`mu300EarlySourceVerified=false` 保持不变。普通启动、默认服务脚本和 Bonjour 均不开放早期媒体能力。没有增加 LuCI 开关或自动修改 procd 配置。

候选新增三个本机参数：

```sh
# 仅在另行授权安装候选、备份、空闲切换后使用。
# 先停止普通桥，保持候选 Agent 单实例运行；不可与原桥抢同一端口。
/usr/lib/airsim/airsim-mu300d --early-media-trial

# 用户已经手动拨号后，在另一个终端授权“当前这一通”。
/usr/lib/airsim/airsim-mu300d --early-media-trial-arm

# 立即撤销媒体试听权限，不发送电话挂断命令。
/usr/lib/airsim/airsim-mu300d --early-media-trial-revoke
```

临时桥进程只有启动后的 10 分钟试验窗口。尚未 arm 时，对当前合法归属的呼出返回 202，方便客户端每 2 秒等待；此时不会启动采集。

arm 命令两次核对当前唯一未接通呼出，并从其持久回执读取 owner 摘要、核对仍属于设备上的已配对密钥，写入默认数据目录下 `early-media-trial.json`（0600）。权限只覆盖该 owner / UUID，期限 60 秒。新旧 UUID、其他配对方不能复用；一次进程窗口绑定后不接受换电话。过期、删除文件、窗口到期、源状态变化会停止媒体；重启普通无参数服务仍为 501。文件不含配对密钥、电话号码或音频。arm 不发 AT、不拨号、不启动音频，实际采集仍须手机完成签名握手。

这是一条明确授权的实验路径，不是把未知硬件认证为生产可用。需在用户批准后使用；下方记录了随后获授权的一次运行。

## 后续无需保存音频的真实试听步骤

由客户端线程取得用户对“候选安装/空闲切换、临时实时下行试听、自己手动测试电话”的授权，并准备支持 202/续期的 iPhone 候选。安装前备份设备原有两个二进制和配置，保留系统、内核、音频模块、DSP 固件、配对及短信。当前只交付开发二进制，尚未制作/验证这一版签名 APK。

1. 空闲时切换到候选 Agent 和临时桥；完成非变更预检。保持已有 AT 服务独占串口。新拨号必须由候选 Agent 生成带 owner 摘要的回执。
2. 用户用 AirSIM 手动拨自己的测试手机。操作者立即执行 `--early-media-trial-arm`，不需要传入或打印号码/密钥；无唯一呼出或身份不可靠则拒绝 arm。
3. 第一轮先保持响铃，再由对方拒接。用户确认是否在 AirSIM 听到真实网络回铃/运营商语音；不保存 PCM、不做语音识别、不发送手机上行。无声不能记为通过；也不能保证运营商每次都会播放公告。
4. 观察 UI 仍为呼叫中、未启动接通计时；记录 EARLYMEDIA、授权、首帧、真实终态和关闭的脱敏时间。真实终态继续走原 ended 链，不因媒体结束就伪造挂断。
5. 原通话确实结束且系统空闲后，另开一个临时桥窗口测试“响铃 → 对方接听”：早期通道退出、资源释放，再开启正常双向 PCM，双方手动确认声音和真实接通计时。
6. 需要撤销时执行 revoke；用户自己挂断通话。空闲后退出临时桥，恢复普通服务启动。异常则恢复已备份的原二进制/服务；不能在活动电话中强行重启。

如果仅出现 EARLYMEDIA 但 arecord 无下行帧、只有静音、来源不明，或必须开启上行才能工作，实机项继续 FAIL；保持默认 501，继续检查 DSP 场景/路由，不以放开 capability 掩盖。也需检查资源退出与内核异常；不得把仿真 PCM 算成运营商声音。
