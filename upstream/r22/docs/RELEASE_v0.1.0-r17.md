# R17 一体安装修订版（开发预览）

R16 的插件包与音频扩展需要分开安装。R17 将已验证的音频扩展合入签名 APK，由安装流程自动校验、备份、安装工具和安排重启后的准备工作，用户不必手工拼装组件。

## 当前适用范围

仅验证 U30 Air / mu300-linux v2026.10.30.1 / OpenWrt 25.12.6，内核 `5.4.254-gb50db5b6224c`，配置 SHA-256 为 `1057cb97e0d2d7f26816e8bf7841faac1153833a01d4893cdc196b75ae6356b3`。这是一体音频包的匹配条件；不能按“1031 之后”推断所有设备可用。F50 / 7.2.8 仍需独立适配和实机验证。

历史版本线：**R16 面向 1031 之后的系统，R12 面向 1031 之前的系统**；日期标签不能替代实际音频匹配条件。R15 已撤回。

## 安装体验

- 一个签名 APK 包含插件、Agent、ALSA、已重建音频模块及所需工具。
- 已有匹配音频扩展直接复用；未知扩展及用户定制准备脚本不自动覆盖。
- 缺少 DSP 固件时，从上游所有者固定 HTTPS 地址下载，并核对固定 SHA-256；已有固件保留，不随 Release 分发用户设备固件。
- 首次需要重启时，LuCI 与安装器明确提示，用户安排一次进入 OpenWrt 的重启，系统自动继续准备。不会自动重启或改动系统/内核镜像。
- 准备未完成时禁止启动、配对与拨号入口；已启用服务须确认新版本桥、Agent 和音频依赖就绪才报告成功。
- 保留 R16 的上行突发帧修复、内存预留保护与 DSP 新应答检查。

## 验证结果

自动化包含 Go race/vet、隔离 Agent、29 项 Node 测试和 10 项一体安装流程测试。签名、安装钩子、包内容与版本检查通过。实机已通过已有音频扩展的完整升级流程，保留了配置与准备脚本，运行服务版本确认为 R17。

已在保留现有音频扩展与固件的 U30 Air 上设置待完成安装状态，真实重启返回 OpenWrt；内存预留、23 个音频驱动、DSP 准备及 R17 桥/Agent 启动全部自动完成。配置、准备脚本、固件与默认启动设置保持原样，未发现内核异常。此项证明重启续接，不等同于清空设备后的首次安装验收；缺失扩展与固件的安装分支由隔离流程测试覆盖。

2026-11-01，用户使用 iPhone AirSIM 手动完成重启后的两通测试，确认双方声音清晰、无卡顿并已挂断。随后只读检查确认通话/媒体均已结束，所有 PCM 流关闭，未发现内核异常。30 分钟通话、多路、其他硬件、公网路径仍未验收。
