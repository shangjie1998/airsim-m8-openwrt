在已验证 R17 一体音频基础上，把 MU300 原生短信库接入 AirSIM 客户端的现有接口：收件箱、变化通知、保存确认和发送。无需修改客户端，也不改变系统、内核或音频组件。

缺少 DSP 固件时先尝试上游固定 HTTPS 地址；上游不可用、被删除或内容校验失败时，自动回退到从本地克隆保存的包内副本。两个来源及安装前副本均校验同一 SHA-256，已有固件保留。备用文件来自公开上游固定提交，不从用户设备导出。详见 [来源及许可记录](https://github.com/kai-wu-cortex/airsim-mu300/blob/v0.1.0-r18/docs/DSP_FIRMWARE_PROVENANCE.md)。上游未提供该独立固件的许可声明，项目许可证不覆盖它。

手机确认保存后仅记录交付标识，保留设备原短信；发送走系统原生 PDU 工具。增加并发保护、两分钟重复提交保护，以及超时/中断时明确报告结果未知、不自动重发。原生短信正文不额外写入 Agent 日志或持久化状态。

基础环境仍为 R17 已验证的 U30 Air / `5.4.254-gb50db5b6224c`，内核配置 SHA-256 为 `1057cb97e0d2d7f26816e8bf7841faac1153833a01d4893cdc196b75ae6356b3`，不覆盖 F50 / 7.2.8。历史 R16 面向 1031 之后版本线、R12 面向 1031 之前版本线；日期不等于硬件兼容证明。

自动化测试已经覆盖协议、鉴权、交付持久化、发送异常及固件回退。R18 首个候选已安装并通过基础检查，对端拒接后的结束同步修复待复测；真实短信收发、后台推送、云端路径和离线固件回退尚未实机验收。本次以开发预览发布，不能将 R17 的通话验收等同于 R18 全功能验收。详见 [短信接入说明](https://github.com/kai-wu-cortex/airsim-mu300/blob/v0.1.0-r18/docs/AIRSIM_SMS.md)。

## 安装与版本选择

**历史版本线必须区分：R16 适用于 1031 之后的系统版本线，R12 适用于 1031 之前的系统版本线。R18 延续新版系统的一体方案，但仍须精确匹配上述 U30 Air 内核及配置；F50 / 7.2.8 不适用。**

下载本 Release 同版 `luci-app-airsim-0.1.0-r18.apk`、公钥和校验清单，或按 [部署手册](https://github.com/kai-wu-cortex/airsim-mu300/blob/v0.1.0-r18/docs/DEPLOYMENT.md) 使用安装器。电话、媒体及短信任务须空闲；保留现有系统、内核、配对与原短信。首次需要重启时须进入 OpenWrt，安装器不更改默认启动系统。

发送短信每条最多 70 字，不支持 emoji、长短信拆分或多 SIM。结果未知时不自动重发。保留可信 R17 包可回退。
