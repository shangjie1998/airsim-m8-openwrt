# R22 · U30 Air 云端早期语音协议对齐

R22 在 R21 的运营商提示音、云端号码和电量修复基础上，增加云端早期语音 v1 显式协商，并在音频握手前后核对真实接通状态。保留 VoWLAN、配对、短信及音频一体安装；音频仍为 8 kHz、单声道、16 位 PCM，不更换系统、内核或 AirSIM 客户端。

## 必须先确认兼容性

**历史版本选型：R16 适用于 1031 之后的 mu300-linux 系统版本线；R12 适用于 1031 之前的旧系统版本线，不得跨版本线混装。** 日期不能替代硬件、内核配置与音频 ABI 检查。

R22 一体包当前只提供以下 U30 Air 音频配置：

| 项目 | 范围 |
| --- | --- |
| 设备 / 架构 | U30 Air / aarch64 |
| 已验证基础系统 | mu300-linux v2026.10.30.1 / OpenWrt 25.12.6 |
| 内核 | `5.4.254-gb50db5b6224c` |
| 内核配置 SHA-256 | `1057cb97e0d2d7f26816e8bf7841faac1153833a01d4893cdc196b75ae6356b3` |
| 软件包 | OpenWrt APK v3，非 Android APK |

**F50 / 7.2.8、其他内核与配置未适配。** 上游系统更新的源码比较不构成 ABI 或实机验收。安装器继续检查匹配条件，不强装音频驱动。

## 本版变化

- 云端客户端必须在 `answer` 媒体订阅中显式发送 `early_media_version: 1` 及匹配的 call_id、call_uuid、generation，才授权接通前下行。缺失身份不能通过旧协议默认值补齐授权。
- 仅允许当前唯一、未接通呼出，且必须有新鲜基带快照和当前通话的 EARLYMEDIA 信号。真实首帧到达后先发送带完整身份的 `early_media_ready_v1`，再发送 PCM。
- 源不可用时发送 `early_media_unavailable`，继续正常呼叫，不挂断、不重拨。接通前不打开麦克风上行，不伪造 active 或提前计时。
- 双向 PCM 打开前及 READY 握手后都复查真实 active/held。传输就绪不能当作对方已接听；结束、替换、过期状态不能继续取得媒体。
- VoWLAN v1、认证与租约保持不变。保留 R21 云端号码、电量、严格通话身份、R20 云模式重复配对和既有短信功能。

## 客户端升级

云端运营商公告需要支持上述 v1 协商的新版 AirSIM。**未协商的旧客户端仍能正常接通后通话，但不会收到 R22 的云端早期语音。** 建议先升级客户端，再升级设备插件。iPhone 171 已补充同时识别 R21 的 `early_media` 与新版 `early_media_ready_v1`；客户端修改和发布由客户端项目完成，本仓库不包含客户端代码改动。

R22 使用新的版本号；R21 保留，可作为匹配设备的回退版本。不要将 R21 安装包、R22 安装脚本及不同版本校验清单混用。

## 验证记录与边界

2026-11-05，用户反馈当前通话体验“验收通过”并授权发布 R22。此前 R21 候选的 VoWLAN / 云端运营商公告、接通前不提前计时、接通后双向声音，以及云端号码、电量显示，均有明确用户确认。

**本线程没有安装新 v1 Agent，不能将上述反馈扩大为 R22 完整 APK 或新协商路径已经单独实机验收。** 本次发布不安装、不重启、不拨号、不发短信、不录音；发布前执行只读设备预检。长通话、多路、断网恢复、真实短信、PR #29 新接口、离线固件恢复和其他硬件仍未完整验收。

发布检查包括插件与全新隔离 Agent 的 Go race/vet、全部 29 项 Node 测试、一体安装及音频保护测试、Linux ARM64 构建、APK 签名和空目录解包、对应源码及许可证核对。协议测试覆盖缺失/过期身份、旧客户端不打开早期源、多通拒绝、源失败保留信令、首帧状态顺序，以及模拟 PCM 握手中状态变化不能提前接通。

## 安装与回退

结束通话和短信任务，保存配置与可信旧包。在符合上表的设备 SSH 终端执行：

```sh
cd /tmp
wget -O airsim-install.sh https://github.com/kai-wu-cortex/airsim-mu300/releases/download/v0.1.0-r22/install.sh
cat airsim-install.sh
sh airsim-install.sh --check
sh airsim-install.sh --install
```

安装器校验固定公钥、哈希、APK 签名及空闲状态，保留配对、配置与原短信。首次需要音频内存准备时提示安排一次进入已有 OpenWrt 的重启，不改变默认系统。详见 [部署手册](https://github.com/kai-wu-cortex/airsim-mu300/blob/v0.1.0-r22/docs/DEPLOYMENT.md)。

附件：`luci-app-airsim-0.1.0-r22.apk`、`airsim-dev.pem`、`install.sh`、`airsim-mu300-0.1.0-r22-sources.tar.gz`、`SHA256SUMS`、`SHA256SUMS.sig`。

发布公钥 SHA-256：`0ce703e76ea4b702194c54b90534d7127874bb38ecda17f7ed6b1add2d2cf1de`。音频包与 DSP 固件哈希不变；缺失固件先从固定上游下载，失败时使用固定副本，两者均校验哈希，已有固件保留。备用固件来自公开上游，不来自用户设备；其独立许可未明确，项目许可证不覆盖它，见 [来源说明](https://github.com/kai-wu-cortex/airsim-mu300/blob/v0.1.0-r22/docs/DSP_FIRMWARE_PROVENANCE.md)。
